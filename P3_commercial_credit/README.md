# Commercial credit scenarios

Debt and working-capital sensitivity for a fictional borrower.

## Run and verify

From this directory:

```powershell
python run.py
python -m unittest -v test_case.py
```

Uses only the Python standard library.

## Saved result and limits

Base/stress ratio calculations, assumption records and a credit memo.

Not a complete three-statement/DCF model, lending decision or real client engagement. All business inputs are fictional. Re-running writes generated evidence to `output/`. [Saved results and assumptions](结果报告.html).
